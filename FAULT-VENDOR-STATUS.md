# Fault Ticket: Pending 3rd Party

Internal staff can select Pending 3rd Party from Update ticket while a ticket is In Progress, On Hold or Pending Customer, with a required comment. Pending 3rd Party has a yellow badge and is available in the status filter. It counts within the existing In progress Dashboard card. Vendor replied — resume work returns it to In Progress; notes, technician assignment, customer-information requests and resolution remain available. Existing history and notifications capture the status change. Requesters cannot change the ticket to this status. Admin can rename or disable the new actions in existing Fault Ticket settings. Old saved settings gain the new status and default enabled actions automatically.

Replace app/main.py, app/static/app.js, app/static/index.html and app/static/style.css. Rebuild Docker and refresh Ctrl+F5. No new dependency or database migration is required.
